# Local Development

## Backend

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements-dev.txt
cp .env.example .env
alembic upgrade head
python scripts/seed_database.py   # optional demo data
uvicorn app.main:app --reload
```

API docs: http://localhost:8000/swagger

## Frontend

```bash
cd frontend
npm install
npm run dev
```

The Vite dev server proxies `/api/*` to `http://localhost:8000` (see
`frontend/vite.config.ts`), so run the backend first.

## Tests

```bash
pytest -q --cov=app --cov-report=term-missing
```

Tests run against an isolated in-memory SQLite database per test
(`tests/conftest.py`) — no external services required. As of this
writing: **25 passed**, ~80% statement coverage on `app/`.

## Lint & type checks

```bash
ruff check app tests scripts
mypy app
```

Frontend:
```bash
cd frontend
npm run lint       # oxlint
npm run typecheck  # tsc --noEmit
```

## Database migrations

```bash
alembic revision --autogenerate -m "describe the change"
alembic upgrade head
```

Always inspect an autogenerated migration before committing it — Alembic
is good but not infallible about enum/type changes.
